# Eye Screening AI — Presentation Website

เว็บไซต์นำเสนอแบบ One-page สำหรับโครงงาน
“ระบบคัดกรองโรคตาเบื้องต้นผ่าน LINE Bot ด้วยปัญญาประดิษฐ์”

## ไฟล์
- `index.html` — โครงสร้างและเนื้อหา
- `styles.css` — ธีม Clean Medical AI + Responsive Layout
- `script.js` — Scroll reveal, navigation state, progress bar, mobile menu

## วิธีเปิด
ดับเบิลคลิก `index.html` หรือเปิดด้วย Live Server ใน VS Code

## ฟอนต์
ใช้ Sarabun สำหรับภาษาไทย และ Nunito สำหรับภาษาอังกฤษ ผ่าน Google Fonts

## หมายเหตุ
เวอร์ชันนี้ตัดเนื้อหา “เปรียบเทียบ MobileNetV2 / EfficientNetB0 / ResNet50”
และตัดตัวเลขผลทดสอบที่ยังไม่ได้ยืนยันออกแล้ว
โดยใช้ MobileNetV2 เป็นโมเดลหลักตามโครงงานเวอร์ชันล่าสุด
